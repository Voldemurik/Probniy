# Демо-профили

`student.csv`, `family.csv`, `maximalist.csv` — временные выписки для вертикального среза (сгенерированы `make_demo.py`,
формат csv-ru, 03.03.2026 — 02.09.2026). Их заменяют файлы генератора AI-1 (`data/generate.py`) вместе с `labels.json`.

Имена файлов зафиксированы в `backend/app/routers/scan.py` (`SAMPLES`): при замене сохраняйте имена или правьте список.
